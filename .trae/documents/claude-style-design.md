# 计划：Claude 风格精致设计重构

## 目标
将现有页面重新设计为 Claude 风格的精致界面，保持所有功能不变。

## Claude 设计风格特点
- 简洁、现代、优雅
- 大量留白，呼吸感强
- 柔和的颜色过渡
- 圆润的边角
- 清晰的层次结构
- 微妙的阴影效果
- 流畅的动画过渡
- 精致的排版

## 设计方案

### 1. 配色方案
```
主背景: #0d0d0d (深黑)
卡片背景: #1a1a1a (稍浅黑)
边框: #2d2d2d (深灰)
文字主色: #f0f0f0 (亮白)
文字次色: #888888 (中灰)
强调色: #ff6b35 (运动橙 - 保留)
成功色: #22c55e (翠绿)
休息色: #3b82f6 (蓝色)
```

### 2. 排版设计

#### 首页 (Setup Screen)
- 居中布局，大量留白
- 标题使用更大字号，字重适中
- 难度选择按钮：无边框，背景渐变，选中时发光效果
- 开始按钮：渐变背景，悬停时微微上浮

#### 训练页面 (Training Screen)
- 视频区域：更大更突出，圆角 24px
- 计时器：超大字号，细体字
- 进度条：更细更精致，渐变色
- 指令文字：居中，呼吸动画更柔和
- 控制按钮：胶囊形状，玻璃拟态效果

#### 完成页面 (Completion Screen)
- 庆祝图标更大
- 文字层次分明
- 按钮突出但不突兀

### 3. 组件样式更新

#### App.vue
- 更新 CSS 变量为新配色
- 增加全局过渡动画
- 优化页脚样式

#### TrainingScreen.vue
- 增加卡片容器，内边距加大
- 视频区域增加阴影
- 进度条更细 (4px)
- 阶段指示器更精致

#### Timer.vue
- 字号加大到 6rem
- 字重 300 (细体)
- 数字等宽字体

#### DifficultySelector.vue
- 按钮改为无边框风格
- 选中状态：背景渐变 + 微光
- 悬停效果更柔和

#### InstructionBox.vue
- 背景更透明
- 边框更细
- 文字居中

#### TipsBox.vue
- 更紧凑的设计
- 列表项间距减小

#### StepDots.vue
- 点更小 (8px)
- 完成状态渐变色

#### CompletionScreen.vue
- 图标动画
- 文字层次优化

### 4. 动画效果
- 页面切换：淡入淡出
- 按钮悬停：微微上浮 + 阴影加深
- 计时器：数字变化时微动
- 进度条：平滑过渡
